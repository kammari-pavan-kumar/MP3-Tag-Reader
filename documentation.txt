
-----------------------------------------------MP3 TAG READER AND EDITOR----------------------------------------------------

----------------------------------------------------------------------------------------------------------------------------

Project Title: MP3 tag reader and editor
----------------------------------------------------------------------------------------------------------------------------


------------------------------------------------------Project Info----------------------------------------------------------
MP3 tag reader is a software which will read and display MP3 (ID3) tag
information from MP3 files.
ID3 is a metadata container most often used in conjunction with the MP3 audio file format. It
allows information such as the title, artist, album, track number, and other information about the file
to be stored in the file itself.
TPE1 -> Artist name
TIT2 -> Title / Song name
TALB -> Album
TYER -> Year
TCON -> Content type
TCOM -> Composer 
The project will be useful to individuals who wish to view and collect
mp3 tag data. This project can be extended to implement a tag editor, where in
users can modify mp3 tag information.

1. Usage - Help
Sample Input:  ./a.out --help song.mp3
Sample Output: 
mp3tag --help
Help Menu
usage: mp3tag -[tTaAycg] 'value' file1
mp3tag -v
-t -> Modifies a Title tag
-T -> Modifies a Track tag
-a -> Modifies a Artist tag
-A -> Modifies a Album tag
-y -> Modifies a Year tag
-c -> Modifies a Comment tag
-g -> Modifies a Genre tag
-h -> Displays this help info
-v -> Prints version info
